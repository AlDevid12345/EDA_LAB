# EDA Lab

This repository contains the work completed for the **Electronics and Communication Engineering (ECE) — EDA Lab**.


## Contents

### Lab1

Contains the first EDA laboratory work, including:

* Diode I–V characteristics
* MOSFET I–V characteristics
* Python analysis scripts
* Experimental/electrical data
* Graphs and plots
* Bonus question work

### Sentaurus_TCAD

Contains semiconductor device simulations and analysis performed using **Synopsys Sentaurus TCAD**, including:

* Device structure and doping analysis
* Cutline analysis
* Electric field and mobility analysis
* Threshold-voltage extraction
* Subthreshold-slope analysis
* Output characteristics
* Breakdown-voltage analysis
* High-field saturation analysis
* Parameter variations such as oxide thickness and fixed charge
* Python scripts for plotting and analysis

## Tools Used

* Python
* NumPy
* Pandas
* Matplotlib
* Synopsys Sentaurus TCAD
* Git / GitHub
